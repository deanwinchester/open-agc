## 阶段三：低风险优化 ✅ 已完成

### 3a. WebSocket 重连优化 ✅
- **现状**：指数退避 1s→2s→4s→...→30s 上限，监听 `navigator.onLine` 事件，网络恢复时主动重连
- **改动**：`app.js` ~20 行
- **效果**：服务器重启后更快恢复连接，减少不必要重试

### 3b. HTML 模板化（`<template>` 元素）❌ 跳过
- **理由**：训练视图剥离后 HTML 从 1646 行降至 ~910 行，模板化的收益已不大，保持现有结构避免风险

### 3c. 聊天记录上限 ✅
- **现状**：消息数超过 100 条时自动移除最早的 50 条
- **改动**：`app.js` `appendMessage()` 函数内 ~5 行
- **效果**：长会话 DOM 节点可控，防止内存膨胀
