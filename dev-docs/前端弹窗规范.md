# 前端弹窗组件规范

## 关闭按钮事件绑定规则

所有弹窗（模态框、浮层、弹出面板）的关闭按钮必须遵循以下规则，防止点击无效：

### 规则一：专用事件监听器（推荐）

为关闭按钮添加独立的事件监听器，使用 `document.getElementById` 直接绑定：

```js
// ✅ 正确 — 直接引用元素，不受子元素影响
document.getElementById('modal-close-btn')?.addEventListener('click', closeModal);
```

适用于：settings.js、app.js、tasks.js 等使用独立事件绑定的模块。

### 规则二：委托事件中的 closest()（插件模块）

在 plugin.js 这类使用单一 `document.addEventListener('click', ...)` 委托模式的模块中，**禁止使用 `e.target.id` 判断关闭按钮**：

```js
// ❌ 错误 — 当按钮内包含 SVG/span/图标时，点击子元素 e.target 不是按钮本身
if (e.target.id === 'modal-close-btn') { closeModal(); }

// ✅ 正确 — closest() 沿 DOM 树向上查找，子元素点击也能正确触发
if (e.target.closest('#modal-close-btn')) { closeModal(); }
```

### 规则三：遮罩层关闭

点击遮罩层关闭弹窗时，使用元素恒等判断：

```js
// ✅ 正确
overlay.addEventListener('click', (e) => {
  if (e.target === overlay) closeModal();
});

// ✅ 或用 e.currentTarget 防止事件委托干扰
if (e.target === e.currentTarget) closeModal();
```

### 为什么禁止 e.target.id？

当按钮包含嵌套子元素（SVG、`<span>`、`<i>` 图标等）时：

```html
<button id="close-btn">
  <svg><!-- 点击这里时 e.target 是 <svg>，不是 <button> --></svg>
</button>
```

点击 SVG 图标时 `e.target.id` 是 `undefined` 或 `""`，永远不会匹配 `'close-btn'`。而 `e.target.closest('#close-btn')` 会沿 DOM 树向上找到 `<button>` 元素。

## 新增弹窗清单

添加新弹窗时请确认：
1. 关闭按钮和取消按钮都绑定了事件
2. 按钮若有 SVG/图标子元素，使用 `closest()` 而非 `e.target.id`
3. 遮罩层点击关闭使用恒等判断
