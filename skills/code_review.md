# 代码审查技能

## 触发条件
当用户要求审查代码、分析代码质量、或进行 Code Review 时。

## 步骤
1. 使用 `read_file` 读取目标代码文件
2. 检查以下维度：
   - **安全漏洞**：SQL 注入、XSS、硬编码密码、不安全的反序列化
   - **性能问题**：N+1 查询、不必要的循环、内存泄漏风险
   - **代码规范**：命名规范、函数长度、重复代码（DRY 原则）
   - **错误处理**：异常是否被正确捕获和处理
   - **可维护性**：注释是否充分、模块划分是否合理
3. 输出结构化的审查报告，按严重程度排序

## 输出格式
```
🔴 严重 — 必须修复
🟡 警告 — 建议修复
🟢 建议 — 可供参考
```

每个问题附具体的修复建议和示例代码。

## 涉及工具
- `read_file` — 读取代码文件
- `execute_shell` — 搜索代码中的模式
